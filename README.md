# Student Record Management System (C) 🎓

A console-based Student Record Management System written in C that stores student records persistently using binary file handling (`students.dat`).

## ✨ Features
- **Add Student:** Add new records with unique roll number, name, course, and marks.
- **View All Students:** Display all saved student records in a formatted table.
- **Search Student:** Find a student record quickly by roll number.
- **Update Record:** Edit existing student details and save changes to the file.
- **Delete Record:** Remove a student record by roll number safely.
